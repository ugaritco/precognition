## Introduction

Ugarit Precognition allows you to anticipate the outcome of a future HTTP request. One of the primary use cases of Precognition is the ability to provide "live" validation in your frontend application.

Documentation for Ugarit Precognition can be found on the [Ugarit website](https://ugarit.com/docs/precognition).
